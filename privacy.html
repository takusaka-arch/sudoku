プライバシーポリシー

数独回答支援アプリ ／ 制定日：2026年10月28日

数独回答支援アプリ（以下「本アプリ」）は、利用者の情報を次のとおり取り扱います。

1. 本アプリが集める情報

本アプリは、利用者の個人情報を開発者のサーバーへ送信・収集しません。広告や利用状況の解析（アクセス解析）も行っていません。

問題・回答中の状態・設定は、利用者の端末のブラウザ内（ローカルストレージ）に保存されます。写真からの問題の読み取りも、端末内で処理され、画像は外部に送信されません。

2. Googleドライブとの連携

利用者が「Googleドライブ」への保存を選んだ場合に限り、本アプリはGoogleアカウントでの接続を求めます。このとき本アプリが使う権限は次のとおりです。

  • drive.file：本アプリが作成したファイル、または利用者が本アプリで開いたファイルだけを読み書きする権限です。Googleドライブ内のその他のファイルを見ることはできません。

本アプリは、この権限を使って、利用者のGoogleドライブの「Sudoku」フォルダに問題や回答中の状態のファイルを保存し、読み込みます。データは利用者の端末とGoogleの間で直接やり取りされ、開発者のサーバーを経由しません。また、開発者が利用者のファイルを見ることはありません。

次回から自動で接続するため、最後に接続したGoogleアカウントのメールアドレスを、端末のブラウザ内にのみ保存します。

Google APIから受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

3. 第三者への提供

本アプリは、利用者の情報を第三者に販売・提供しません。

4. 連携の解除とデータの削除

  • アプリの「接続を解除」を押すと、端末に保存したアカウント情報が消え、Googleドライブとの接続が終わります。
  • 本アプリへのアクセス許可は、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
  • Googleドライブに保存したファイルは、利用者がGoogleドライブ上で自由に削除できます。
  • 端末内のデータは、ブラウザのサイトデータを削除すると消えます。

5. お問い合わせ

本ポリシーについてのお問い合わせは、takuma.sakai@gmail.com までご連絡ください。

6. 改定

本ポリシーを改定した場合は、このページでお知らせします。
